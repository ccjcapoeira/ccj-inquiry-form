# Looker Studio 手順（v1）

対象: 1行が1件の「リード台帳」。本書の「問い合わせ数」は人数ではなく受付件数です。UIでは Data Studio と表記される場合もあります。

## 接続

1. 台帳に実送信テストの1行が入ったことを確認します。
2. [Looker Studio](https://lookerstudio.google.com/) で空のレポートを作ります。「データを追加」→「Google スプレッドシート」を選びます。
3. 作成したスプレッドシートから「リード台帳」を選びます。「先頭行をヘッダーとして使用」を有効にし、データ範囲を `A:AF` として接続・レポートに追加します。
4. データソースのフィールド一覧を開き、「ID」はテキスト、「受付日時」は日付と時刻、「体験日」「入会日」は日付に設定します。年齢や電話番号を件数の集計項目にしません。
5. 最初に体験日・入会日が全件空欄だとテキスト型と判定される場合があります。実際の日付を入力した後でフィールドの型を再確認します。元のシートでは日付として入力し、空欄には文字を入れないでください。
6. レポートに期間コントロール、クラスと教室のプルダウンを追加。期間の基準フィールドを「受付日時」にします。メモに「動作確認」「集計対象外」を含む行を除外するフィルタも各ページに適用します。

## 計算フィールド

チャートの指標で「フィールドを追加」し、以下を作成します。日本語の列名は式エディタからフィールド候補を選んで挿入してください。

| 名前 | 式 | 表示形式 |
|---|---|---|
| 問い合わせ数 | `COUNT(ID)` | 数値 |
| 体験数 | `COUNT(体験日)` | 数値 |
| 入会数 | `COUNT(入会日)` | 数値 |
| 体験率 | `CASE WHEN COUNT(ID) = 0 THEN 0 ELSE COUNT(体験日) / COUNT(ID) END` | パーセント |
| 入会率（問い合わせから） | `CASE WHEN COUNT(ID) = 0 THEN 0 ELSE COUNT(入会日) / COUNT(ID) END` | パーセント |

COUNTは空（NULL）の日付を除きます。未定・ハイフンを入れた文字列列では正しく数えられないため、必ず日付型にしてください。空欄が0件扱いにならない場合は、型とシートの空欄を先に修正します。

「体験から入会」の分子は **体験日と入会日の両方がある件数** にします。直接入会を含む `COUNT(入会日) / COUNT(体験日)` では100%を超え得るため、次の式を使います。

```text
CASE WHEN COUNT(体験日) = 0 THEN 0
ELSE SUM(CASE WHEN 体験日 IS NOT NULL AND 入会日 IS NOT NULL THEN 1 ELSE 0 END) / COUNT(体験日)
END
```

名前は「体験後入会率」、形式はパーセントです。式を実環境で保存できることと、台帳を手で数えた数に一致することを確認してください。実アカウントでの式保存は今回未実施です。

## ページ構成

1. **月別の問い合わせ**: 時系列グラフ。ディメンション「受付日時」を年月単位にし、内訳「クラス」、指標「問い合わせ数」。全体件数のスコアカードも置きます。
2. **最初の接点**: 横棒グラフ。ディメンション「最初の接点」、指標「問い合わせ数」。別の表に `utm_source / utm_medium / utm_campaign` と件数を置きます。自己申告と自動計測は異なる情報なので上書き・統合しません。UTM空欄は「不明」であり、Google自然検索とは断定しません。
3. **問い合わせ→体験→入会**: 問い合わせ数・体験数・入会数・体験率・入会率・体験後入会率のスコアカード。体験を経ない入会があるため、3件数の棒は厳密な段階ファネルではありません。
4. **教室別**: ディメンション「教室」、指標は問い合わせ数・体験数・入会数・各率の表。「未定」も表示します。
5. **見送り理由**: 「ステータス」が「見送り」または「連絡途絶」の行を対象に、ディメンション「見送り理由」、指標「問い合わせ数」の横棒グラフ。理由空欄も未記入として把握します。

## 集計の意味・確認

- 全ページの期間は **問い合わせ受付月の集団** を絞ります。9月に問い合わせ、10月に入会した人は「9月受付の入会」に含みます。10月中に発生した入会数とは別です。
- 見学や取材も全問い合わせに含みます。「体験申込だけ」を見たいときは「種別 = 体験」のフィルタを追加し、分母を明示します。
- 初回チェックでは全体件数、特定教室の件数、体験日・入会日が入っている件数をシートと照合します。期間内0件でエラーにならないことも確認します。
- 個人名・メール・メッセージをグラフに出さず、共有は運営関係者限定にします。一般公開リンクは作りません。

参考（2026-09-13確認）: [Google Sheetsへの接続](https://docs.cloud.google.com/data-studio/connect-to-google-sheets)、[COUNT](https://docs.cloud.google.com/data-studio/count)。
